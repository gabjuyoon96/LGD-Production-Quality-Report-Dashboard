# LGD-Production-Quality-Report-Dashboard

## 📌 프로젝트 소개

LG디스플레이 직무 교육 과정에서 제작한 **생산·품질 업무 보고서 웹 대시보드**입니다.

가상의 생산 LOT 데이터와 설비 이력 데이터를 기반으로 생산량, 목표 달성률, 검사 수량, 불량률 등을 조회하고, 조회 결과를 근거로 생산·품질 보고서를 작성할 수 있도록 구현했습니다.

또한 Three.js를 활용하여 패널 검사 및 이송 설비를 3D 형태로 시각화했습니다.

## 💡 주요 기능

### 1. 생산 데이터 조회

조회 기간과 생산 라인을 선택하여 LOT별 생산 데이터를 확인할 수 있습니다.

조회 가능한 주요 데이터는 다음과 같습니다.

* 생산 목표 수량
* 실제 생산 수량
* 생산 달성률
* 검사 수량
* 불량 수량
* 불량률

생산 달성률은 다음과 같이 계산합니다.

`생산 달성률 = 생산 수량 ÷ 목표 수량 × 100`

불량률은 다음과 같이 계산합니다.

`불량률 = 불량 수량 ÷ 검사 수량 × 100`

---

### 2. LOT별 생산·품질 데이터 확인

조회 기간에 해당하는 생산 기록을 LOT 단위로 확인할 수 있습니다.

표시 항목은 다음과 같습니다.

* 일자
* 생산 라인
* LOT 번호
* 목표 생산량
* 실제 생산량
* 검사량
* 불량량

---

### 3. 일자별 불량률 시각화

생산 데이터를 기반으로 일자별 불량률을 계산하고 Bar 형태로 시각화합니다.

이를 통해 특정 일자의 품질 이상 여부를 보다 직관적으로 확인할 수 있도록 구성했습니다.

---

### 4. 설비 이벤트 확인

조회 기간 중 발생한 설비 관련 이벤트를 생산 데이터와 함께 확인할 수 있습니다.

예시 이벤트

* 설비 모의 정지
* 온도 주의
* 정상 복귀 여부
* 미해제 설비 이상

생산·품질 수치뿐만 아니라 설비 이력도 함께 확인하여 보고서 작성의 근거로 활용할 수 있도록 구현했습니다.

---

### 5. 3D 생산 설비 시각화

Three.js와 WebGL을 활용하여 디스플레이 패널 검사·이송 설비를 3D로 구현했습니다.

구현 요소는 다음과 같습니다.

* Roller Conveyor
* Inspection Equipment
* Display Panel
* Inspection Camera
* Operator Station
* Tower Lamp
* 패널 이송 Animation

마우스를 이용하여 설비를 회전하거나 확대·축소하여 확인할 수 있습니다.

---

### 6. 생산·품질 보고서 자동 생성

조회한 생산 및 품질 데이터를 기반으로 업무 보고서 초안을 자동으로 생성합니다.

보고서에는 다음 내용이 포함됩니다.

* 조회 기간
* 생산량
* 목표 생산량
* 생산 달성률
* 검사량
* 불량량
* 불량률
* LOT 기록
* 설비 이벤트
* 현재 모의 설비 상태
* 추가 확인 사항

---

### 7. 보고서 검토 및 저장

생성된 보고서를 사용자가 직접 수정할 수 있으며, 데이터와 내용을 확인한 후 **검토 완료 상태**를 저장할 수 있습니다.

수정된 보고서는 JSON 형태로 관리합니다.

---

### 8. 보고서 다운로드

저장된 보고서를 다음 형식으로 다운로드할 수 있습니다.

* `.txt` : 최종 업무 보고서
* `.json` : 보고서 작성에 사용된 근거 데이터

이를 통해 **보고 내용과 원본 데이터의 추적 가능성(Traceability)**을 확보하도록 구성했습니다.

## 📊 활용 데이터

본 프로젝트에서 사용되는 생산 및 품질 데이터는 실제 기업 데이터가 아닌 **교육 목적의 가상 데이터**입니다.

예시 데이터 항목

| 항목        | 설명     |
| --------- | ------ |
| Date      | 생산 일자  |
| Line      | 생산 라인  |
| LOT       | 생산 LOT |
| Target    | 목표 생산량 |
| Produced  | 실제 생산량 |
| Inspected | 검사 수량  |
| Defects   | 불량 수량  |

생산 라인은 Line A와 Line B로 구분하여 구성했습니다.

---

## 🎯 프로젝트 목적

본 프로젝트의 목적은 단순한 데이터 조회가 아니라,

**생산 데이터 확인 → 품질 지표 분석 → 설비 이력 확인 → 업무 보고서 작성**

과정을 하나의 웹 환경에서 경험하는 것입니다.

이를 통해 제조업 생산·품질 업무에서 중요한 데이터 기반 업무보고 프로세스를 이해하고자 제작했습니다.
